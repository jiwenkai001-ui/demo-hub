# 静态资源与业务模块约定

日期：2026-11-17；执行者：Codex。

- 先遵循根目录 `AGENTS.md` 和 `DESIGN.md`。
- 所有 JS 使用普通脚本与 `window.YMM` 命名空间，便于离线提供资源；无远程 imports。
- `seed.js` 只负责种子数据；`store.js` 负责可测试的业务规则；`ui.js` 负责公共界面；`admin.js` 和 `school.js` 负责页面交互。
- 写入 localStorage 失败必须反馈；业务变更先校验，成功持久化后才替换内存状态。
- HTML 展示用户输入前转义，表单遵守公共校验与弹窗模式；公共方法用中文说明参数约束、返回和错误语义。
- 同一对象的状态变更只走 store 命令，禁止 UI 直接递增库存或另存财务汇总。
- 所有图片保存在 `images/`，实际 UI 使用原生文字和控件，不能以截图充当页面。
- 筛选输入保持即时渲染和焦点，避免用户点击行操作时被挂起的 debounce 替换 DOM。
- `createOrder({clearCart:true})` 将下单与清空学校购物车原子保存，禁止拆成两个可能分别失败的存储动作。
- 毛利图纵轴的“万元”应从分除以 1000000，不是除以 100000。
- 负数供应商账单表示退货退款，`paid` 和收付款流水按同方向带符号记录；余额校验比较绝对值。
- 商品有库存或历史单据时禁止直接修改计价单位；日期必须校验真实日历值，不能只匹配 YYYY-MM-DD 格式。
