# 汉服排队叫号 Demo 设计规范

## 1. 视觉方向
- 业务场景：汉服商户高峰接待，核心是“有秩序、可感知、叫号明确”。
- 气质关键词：国风、雅致、温润、秩序感。
- 设计语言：浅色宣纸底 + 酒红主色 + 墨色标题，强调“传统气质 + 现代效率”。

## 2. 主题变量（统一入口）
- 统一入口：`assets/common.css` 的 `:root`。
- 主色：`#a82f42`（关键动作、按钮）
- 深主色：`#7c1f30`（按钮渐变终点）
- 辅色：`#0e6d68`（次操作、重呼）
- 警告色：`#c9741c`（过号）
- 成功色：`#228257`（完成）
- 边框与底色：`#e4d6c6` / `#f6ece1`

## 3. 组件一致性约束
- 按钮统一使用 `.btn` + 变体：`.btn-primary/.btn-accent/.btn-warning/.btn-success/.btn-ghost`。
- 数据卡片统一使用 `.panel`、`.queue-item`。
- 空状态统一使用 `.empty` 或 `.muted`。
- 响应式规则统一在 `common.css` 的 `@media (max-width: 980px)` 控制。

## 4. 页面模式
- `index.html`：品牌说明 + 双端入口 + 顾客端二维码扫码区。
- `customer.html`：单队列取号、我的号单、队列概览。
- `merchant.html`：单队列叫号控制台、等待/过号/完成列表。

## 5. 交互规则
- 顾客端不做业务分类，点击即加入同一队列。
- 同一手机当天仅允许一个有效号单，重复扫码展示已有进度。
- 商户端单按钮“叫下一位”，其余控制为重呼/过号/完成。
- 过号后可从“过号队列”单独重呼，方便现场回流。

## 6. 统计接入约束
- 当前 Demo 默认不注入统计脚本。
- 仅在用户明确指定需要埋点的项目里再单独接入统计能力。

## 7. 多语言约束
- 当前 Demo 默认支持中文/英文切换，四个页面语言行为保持一致。
- 语言切换组件统一使用 `.lang-switcher` 与 `.lang-btn`。
- 翻译词典集中维护在 `assets/i18n.js`，避免在页面脚本中散落硬编码文案。
