# hanfu-queue-demo

汉服商户排队叫号演示系统（双端单队列：顾客端 H5 + 商户端 H5）。

## 1. 功能概览

- 顾客端 H5：扫码后取号、查看我的号单、查看队列概况。
- 商户端 H5：扫码后一键叫下一位、重呼、过号、完成、重置演示数据。
- 扫码模拟：总入口页仅生成顾客端二维码，手机可直接扫。
- 每日单号规则：同一手机当天仅允许持有一个有效号单（等待/已叫/过号）；有效期间再次扫码会直接查看进度。
- 中英文切换：四个页面统一支持中文/英文一键切换，并记住上次语言。
- 实时同步：通过 `serve_demo.py` 的 `/api/*` 在多设备间同步状态。

## 2. 本地启动

在项目目录执行：

```bash
py -3 serve_demo.py --host 0.0.0.0 --port 8800
```

打开：

- 总入口：`http://127.0.0.1:8800/index.html`
- 顾客端：`http://127.0.0.1:8800/customer.html`
- 商户端：`http://127.0.0.1:8800/merchant.html`

## 3. 对外演示（任意地址可访问）

### 局域网演示

1. 保持服务使用 `--host 0.0.0.0` 启动。
2. 找到当前机器 IP（如 `192.168.1.20`）。
3. 客户设备访问 `http://192.168.1.20:8800/index.html`。

### 公网演示

可将项目目录放到任意服务器并运行同样命令，或使用 Nginx 反向代理到 `8800` 端口。

## 4. 演示建议脚本

1. 在商户端点击“重置演示数据”。
2. 用顾客手机扫码取号，再次扫码可看到相同号单进度。
3. 商户端点击“叫下一位”，演示“过号 -> 重呼 -> 完成办理”闭环。

## 5. 目录结构

- `index.html`：总入口
- `customer.html`：顾客取号端
- `merchant.html`：商户叫号端
- `assets/`：样式与脚本
- `serve_demo.py`：静态服务 + API
- `data/state.json`：演示状态持久化文件
- `DESIGN.md`：设计约束

## 6. 跨域与统计说明

- 当前服务默认开启 CORS：`Access-Control-Allow-Origin: *`（允许所有域名跨域）。
- 当前 Demo 默认不接入任何统计埋点代码。
- 后续仅在你明确指定的项目中再按要求接入埋点。
