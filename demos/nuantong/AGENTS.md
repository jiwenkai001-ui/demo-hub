# 暖通业务协同演示 Demo 模块说明

日期：2026-07-14
执行者：Codex

## 项目结构

- `index.html`：静态入口，浏览器直接打开即可演示。
- `styles.css`：项目唯一样式入口，遵循根目录 `DESIGN.md`。
- `app.js`：Demo mock 数据、页面渲染和交互逻辑。
- `DESIGN.md`：项目唯一设计约束源。
- `.codex-log/`：本次任务过程与验证留痕。
- `.codex-tmp/`：临时文件目录。

## 技术决策

- 当前 Demo 只做浏览器静态演示，不引入后端、数据库、真实微信小程序、真实电子签或厂家云仓接口。
- 使用纯 HTML/CSS/JavaScript，降低演示和拷贝成本。
- 数据全部写在前端 mock 中，便于现场快速调整文案、金额、订单状态。
- Umami 统计仅预留生产环境启用逻辑，本地不会发送统计。

## 注意事项

- 修改 UI 前先阅读 `DESIGN.md`，不要在页面中新增未命名的视觉风格。
- 不要把真实客户手机号、合同、收款凭证写入 mock 数据。
- 不要把电子签、云仓、用友财务等第三方接口伪装成已对接；Demo 中统一标注为模拟状态。
- 若后续改成正式微信小程序，应重新拆分页面路由、接口和权限模型。
