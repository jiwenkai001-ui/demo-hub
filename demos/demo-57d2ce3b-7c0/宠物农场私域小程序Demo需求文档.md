## 一、产品定位

### 1.1 业务背景

客户运营线下宠物农场，前期依靠线上公域（抖音、小红书、大众点评等）引流获客，游客到店后缺乏沉淀与复购链路，存在以下痛点：

| 痛点维度 | 现状描述 |
|---------|---------|
| 流量流失 | 公域引来的游客到店一次后流失，无法二次触达 |
| 缺少会员资产 | 无自有会员体系，客户数据散落各处，无法分层运营 |
| 活动管理低效 | 农场活动预约靠人工登记，核销混乱，库存难以管控 |
| 变现渠道单一 | 仅靠门票收入，宠物用品消费外流至电商平台 |
| 养宠服务缺失 | 无疫苗接种提醒、健康档案等长期服务触点 |

### 1.2 产品目标

搭建一套**私域小程序**，将公域流量沉淀为自有会员，通过"内容+服务+商品"三位一体的运营闭环，实现客户长效留存与持续变现。

```
公域引流 → 到店体验 → 沉淀会员 → 内容留存 → 服务复购 → 商品变现 → 裂变增长
```

### 1.3 产品定位

| 维度 | 定位 |
|------|-----|
| 产品名称 | 「萌宠农场」（暂定） |
| 产品类型 | 微信小程序（私域运营载体） |
| 目标用户 | 18-40岁养宠人群、宠物爱好者、亲子家庭 |
| 核心价值 | 以线下农场体验为信任基石，线上提供养宠内容、活动预约、商品购买、会员服务的一站式私域平台 |
| 差异化优势 | 依托实体农场场景，"体验+内容+商品"闭环，非纯电商或纯内容平台 |

### 1.4 核心模块总览

```
萌宠农场小程序
├── 宠物社群（内容+社交+服务）
│   ├── 喂养知识专栏
```

#### 活动预约核心流程

```
活动详情 → 选择日期/时段 → 选择人数/宠物 → 填写联系人
    → 使用优惠券/积分 → 支付 → 生成订单+核销券码
    → 到店出示券码 → 店员扫码核销 → 订单完成 → 邀请评价
```

#### 分时预约时段设计

| 活动类型 | 时段规则 | 每时段容量 |
|---------|---------|-----------|
| 撸宠体验 | 09:00-11:00 / 13:00-15:00 / 15:00-17:00（周末加 10:00-12:00） | 15人/时段 |
| 萌宠互动 | 10:00-11:00 / 14:00-15:00 / 16:00-17:00 | 8人/时段 |
| 主题活动 | 按活动配置自定义时段 | 按活动配置 |

## 四、核心业务流程

### 4.1 用户注册与会员沉淀流程

```
公域引流（抖音/小红书/点评）
    → 扫码进入小程序
    → 微信授权登录
    → 首次进入引导完善信息（手机号+基础资料）
    → 自动成为L1萌新宠友
    → 引导添加宠物档案（赠送积分奖励）
    → 引导浏览首页/领取新人券
    → 后续运营触达（订阅消息/社群）
```

### 4.2 活动预约到核销完整流程

```
用户浏览活动 → 查看活动详情 → 选择日期/时段
    → 选择人数/宠物 → 填写联系人 → 使用优惠券/积分
    → 微信支付 → 订单生成 + 核销券码
    → 订阅消息推送预约成功通知
    → 提前1天推送提醒
    → 到店出示券码 → 店员扫码核销
    → 订单完成 → 推送评价邀请
    → 积分发放 → 会员成长值更新
```

### 4.3 疫苗提醒自动化流程

```
用户添加宠物档案 → 登记疫苗记录（填写下次接种日期）
    → 系统自动创建提醒任务
    → 提前7天：订阅消息推送第1次提醒
    → 提前3天：订阅消息推送第2次提醒
    → 提前1天：订阅消息推送第3次提醒
    → 到期日：最终提醒 + 一键预约接种入口
    → 用户完成接种 → 登记新疫苗记录 → 循环
```

### 4.4 商品购买与履约流程（快递）

```
浏览商品 → 加入购物车/立即购买 → 确认订单
    → 选择收货地址（快递发货）→ 使用优惠券/积分
    → 微信支付 → 订单生成
    → 后台发货 → 填写物流单号
    → 用户查看物流 → 确认收货
    → 订单完成 → 积分发放 → 邀请评价
```

### 4.5 商品购买与履约流程（自提）

```
浏览商品 → 加入购物车/立即购买 → 确认订单
    → 选择自提门店（到店自提）→ 使用优惠券/积分
    → 微信支付 → 订单生成 + 自提核销码
    → 用户到店 → 店员扫码核销
    → 订单完成 → 积分发放 → 邀请评价
```
