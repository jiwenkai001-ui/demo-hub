# 第三方组件

前端界面、业务服务与测试为本次重构编写；未依赖在线字体、在线图表或在线业务接口。

| 组件 | 版本 | 用途 | 许可证位置 |
|---|---|---|---|
| jsQR | 1.4.0 | 浏览器摄像头二维码解码 | static/jsQR-LICENSE.txt（Apache-2.0） |
| qrcode | 8.2 | 实际生成二维码 | vendor/qrcode-8.2.dist-info/LICENSE |
| Pillow | 13.0.0 | 图片处理、附件校验、PNG 导出 | vendor/pillow-13.0.0.dist-info/licenses |
| ReportLab | 5.0.1 | PDF 报告与二维码排版 | vendor/reportlab-5.0.1.dist-info/licenses |
| openpyxl | 3.1.5 | Excel 报告 | vendor/openpyxl-3.1.5.dist-info/LICENCE.rst |

Python 依赖所带元数据及上游许可证一并保留在 vendor。jsQR 来源为 npm jsqr@1.4.0 的公开发布包（cdn.jsdelivr.net），代码已保存本地，运行不请求 CDN。二维码 SVG、图标、示意图与数据图表均由本系统生成。
