# 标智 AI · 纯前端演示

直接双击 `index.html` 即可使用，无需安装依赖或启动后端。也可使用静态服务器预览。

## 演示流程

1. 工作台点击“新建投标项目”，填写项目资料，选择文件或使用示例文件。
2. 体验模拟解析，查看资格要求、评分标准及关键风险。
3. 点击“开始编写标书”，选择章节，编辑正文，保存或体验示例优化。
4. 进入“合规检查”，填写处理记录，补充材料或确认修订。
5. 导出可由 Word / WPS 打开的 `.doc` 兼容文档，或导出检查清单。
6. 逐章核验并保存全部 8 章，处理项目检查事项后提交审核，再确认审核完成。完成后修改正文会重新进入编写状态。

另含企业资料分类、搜索、资料上传索引、模板选择、新建项目、项目搜索筛选、工作动态、数据备份与重置。界面适配桌面及手机浏览器。

## 数据边界

- 所有初始项目、企业资料、条款、页码、评分及风险均为示例数据。
- 上传操作仅保存文件名称和填写的信息，不读取文件内容、不保存原件、不上传服务器。
- 文档解析、AI 编写和合规检测均为前端模拟，未连接 AI 或 OCR 服务。
- 项目及修改保存在当前浏览器的 localStorage 中，可在设置中心导出 JSON 备份或重置。
- 本地保存失败时显示持续提示，可重试保存或导出当前页面的数据。检测到其他窗口更新后停止写入，需先备份再加载最新数据；不提供多人协同合并。
- 文件选择限制为 PDF、DOC、DOCX、TXT、PNG、JPG/JPEG，文件不能为空且不超过 20 MB；仅校验名称和大小，不执行真实内容安全扫描。
- 项目及资料列表每页展示 12 条，搜索覆盖全部记录。
- 支持浏览器前进、后退，以及刷新后恢复项目和章节位置。
- 导出格式为 Word 兼容 HTML `.doc`，并非原生 `.docx`；可用 Word / WPS 打开后另存为 `.docx`。
- 这是一份浏览器演示网页，不是可直接提交微信审核的小程序工程。

## 文件

- `index.html`：入口
- `styles.css`：界面样式及移动端适配
- `app.js`：交互、示例数据、本地保存和导出
- `favicon.svg`：本地应用图标

## 自动化验证

运行环境为 Windows、已安装的 Microsoft Edge，以及 Python Playwright。打开演示本身不需要这些测试依赖。

```powershell
python audit_system.py
python verify_demo.py
```

`audit_system.py` 覆盖异常数据、注入、异步编辑、保存失败、窗口冲突、文件校验、性能和响应式布局等专项场景。`verify_demo.py` 覆盖完整操作流程。所有浏览器测试使用独立上下文和合成数据，不使用用户的浏览器配置。

也可设置 `BID_DEMO_URL=http://127.0.0.1:8765/`，让 `verify_demo.py` 验证正在运行的静态预览。

测试记录见 `audit-results.json` 和 `verification-results.json`，首次专项检查记录见 `audit-baseline.json`。详细发现与适用边界见 `系统测试报告.md`。

纯本地资源，无外部 CDN、字体或网络接口依赖。
