# JavaScript 模块

日期：2026-11-17；执行者：Codex。

- 使用普通 defer 脚本和 JMY 命名空间，按 seed、store、ui、pages、forms、app 顺序加载。
- store.execute 是业务写入唯一入口：复制状态、校验和变更成功后再保存，异常不产生部分写入。
- 所有聚合指标从当前订单、批次、收款和生产记录计算。
- ui 负责通用表格、筛选、弹窗、下载和图标；pages 负责后台渲染；forms 负责编辑与事务提交；client 负责订货端。
- 动态文本必须经过 HTML 转义，金额使用整数分；表单无效时保留输入并显示原因。
- 月度筛选使用seed.js的monthEnd计算合法月末，不拼接固定31日。
- 客户端使用独立详情与复购动作，只显示当前客户资料；购物车按客户分键，重置时统一清理。
- print.js的缺货断言针对商品表格，订单备注可能提及缺货产品；签收后的历史单据保留原明细。
