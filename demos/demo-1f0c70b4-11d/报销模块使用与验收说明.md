# 宠物医院 Demo · 双报销模块

版本：2026-11-11。管理端新增“宠物医疗报销”和“院内费用报销”，配合原 OA、病历、收费和客户端使用。所有新增案例、保单和费用凭证均为虚构演示。

## 打开与入口

完整解压后双击 index.html 或“启动宠物医院.cmd”，无需安装、后端或联网。建议用最新版 Edge / Chrome。

- 工作台“报销办理”显示两类报销的待办数，点击进入对应模块。
- 宠物医疗报销也可从已结清账单详情的“发起医疗报销”进入，自动带入账单。
- 院内费用报销统一在费用中心新建，也可从 OA 顶部或常用办公进入；OA不再提供重复的新建报销简表。历史 OA 报销详情仍可“转入费用报销”。
- 客户端首页、我的和已支付账单可查询本人医疗报销进度与详情。

## 宠物医疗报销

包含报销工作台、报销案件、宠物保单、材料与流程四个页签。初始提供9份不同处理状态的医疗报销案例，便于直接演示。

办理顺序：选择宠物已结清且有实际支付的医疗账单 → 选择该宠物保单 → 核对事故情况和收款人 → 整理材料 → 提交院内审核 → 模拟保险审核与核定金额 → 登记模拟赔付。支持补件、驳回、撤回、重开和赔付冲正，操作保留时间线。

系统自动整理本次病历、费用清单和结算凭证的文本快照；有关联检查时提示补充检验影像。宠物身份和保单凭证可上传附件，或填写明确的虚构演示材料说明。文本快照和演示说明不能替代正式票据。材料支持预览、逐份下载及导出案件材料清单。

预估按虚构参数计算：min(max(合规费用－免赔额, 0) × 赔付比例, 单次限额, 保单年度剩余额度)。优惠按费用项目原金额比例分摊，可勾选除外项目。页面分别展示医疗实付、合规费用、预估、模拟核定和赔付流水。

同一账单不能同时建立重复有效案件；保单、宠物和账单归属必须一致。核验保障日期、等待期、事故与就诊日期、诊断、材料和剩余额度。待赔付与已赔付占用保单年度额度，撤回或冲正释放额度。已进入审核或已赔付案件会阻止原账单直接退费，需先撤回或冲正。

保险赔款单独记录，不增加医院医疗营收、不修改原账单已付金额，也不影响会员余额或库存。客户端只显示本人案件及脱敏账号，不提供医院内部原始附件下载。

## 院内费用报销与审批流

适用于药品耗材、设备维修、差旅培训、行政办公等院务支出。每单包含申请人、事由、收款信息、1至30条费用明细、票据附件和流转记录。提供8份不同状态的虚构示例。

流程：草稿 → 科室审核 → 财务复核 → 待付款 → 已付款。报销总额达到3000元时，在财务复核后增加“院长审批”。各节点以演示身份操作，页面显示当前阶段和后续步骤。

审核可通过、退回补正或带原因驳回；申请可撤回或重开。补正后重走科室审核，确保修改后的金额、用途和收款信息重新经过核对。审批通过后由出纳填写付款日期、方式和唯一凭证号，支持带原因冲正，保留原付款和负数冲正记录。

日期不能晚于今天、金额最多两位小数、票据号不可在有效报销单间重复使用；提交前必须有附件、费用明细和收款信息。付款日期限定在提交日与今天之间，未完成全部审批不能付款，重复审批和重复付款会被拦截。

OA 原报销可转入独立费用中心，原申请保留。转入操作幂等，不会重复生成；转入后原 OA 审批按钮关闭，后续统一在费用中心审核，补齐票据和收款资料后再提交。原 OA 已通过的申请也要在费用中心重新走完整流程，避免缺少财务复核便直接付款。

院内报销为医院支出登记，和宠物医疗赔款、收费台医疗收入分别记录。

## 附件和保存

两模块仅支持 PNG、JPG、PDF 附件，每份不超过3MB，每单最多15份、合计不超过12MB，校验文件内容与类型。演示种子另有明确标识的文本说明。

数据、附件和修改保存在当前浏览器 IndexedDB。刷新保留；同浏览器、同打开方式的管理端与客户端共享数据并通知更新；有未提交输入时保留输入并提示更新。不同浏览器、不同电脑、不同打开方式不自动同步。原始种子与数据库不改写，新内容通过幂等迁移追加。

收款账号仅保存末4位掩码；请使用虚构演示资料。清除站点数据、使用无痕模式或换目录可能影响本地保存，演示前建议使用固定目录和浏览器。

## 参考依据和边界

功能设计参考 ezyVet、Shepherd 的诊疗记录与账单联动，以及平安、PetSure、ManyPets、Pumpkin 官网的材料、审核与赔付流程。准确来源与差异见 docs/宠物医疗报销参考资料.md。

本版采用先付后赔示例。保险审核、审批身份和付款均为本地模拟，不向保险公司提交资料、不执行资金划转、不构成真实保险产品或合作医院声明。实际责任、时限、医院资质、票据和材料要求以有效合同及承保机构通知为准。
