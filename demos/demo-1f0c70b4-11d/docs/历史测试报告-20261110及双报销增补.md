## 联调与异常边界

实际走通并核对数据和刷新后保存结果：

1. 客户端预约 → OA班次校验 → 接诊 → 病历/体征/SOAP → 开药扣库存批次 → 检验/影像计费和客户报告 → 优惠支付 → 客户消费与经营统计。
2. 前一天开单 → 今天会员卡与现金分次收款 → 次日退款；流水、统计日期、卡余额和客户消费一致。
3. 营销发券 → 客户选券 → 统一结算只核销一次 → 营销转化 → 退款恢复券并撤销转化；全额券0元正确结清。
4. 库存预警 → 带商品补货 → 采购部分/全部收货 → 批次变化 → 处方扣减和撤药精确恢复。
5. 已有预约 → 请假/改班冲突拦截 → 处理冲突后审批 → 排班标记请假 → 两端不可继续约该医生。
6. 两个真实file://窗口修改共享数据库 → 空闲页面自动更新 → 弹窗或已失焦的未提交输入保留 → 手动刷新可取消或确认。

异常检查涵盖归属不匹配、错误日期/体征、重复提交、负数和超额收款、余额不足、无效券、超收、负库存、维护设备、空结果审核、已付费用修改、关闭问诊发送、跨客户操作、慢请求覆盖、并发审批只成功一次、失败事务回滚。
