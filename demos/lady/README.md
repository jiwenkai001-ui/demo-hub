# LADY FASHION 门店管理系统 Demo

这是一个给客户演示用的纯静态 Demo，主题已改为“女装双店铺管理系统”。

当前版本满足这些需求：

- 默认进入中文
- 支持中英文切换
- 带登录界面，可用演示账号登录
- 支持 2 个店铺管理
- 包含销售额、同比、环比、趋势分析
- 包含库存查询、库存预警、出入库记录、店铺调拨
- 商品示例包含睡衣、内衣、睡裤、内裤等女装相关品类

## 当前文件

- `index.html`
  页面结构，包含登录页和后台页面
- `styles.css`
  页面样式与响应式布局
- `app.js`
  演示数据、双语言、登录逻辑、图表渲染、筛选交互

## 本地查看

最简单的方法：

1. 直接双击 `index.html`
2. 浏览器里先登录
3. 登录后切换中英文、店铺、页面模块查看演示效果

如果你想用本地地址方式预览：

### Python

```bash
python -m http.server 8080
```

然后打开：

```text
http://127.0.0.1:8080
```

### Node.js

```bash
npx serve .
```

## 服务器部署

这是纯静态项目，部署时把以下文件上传到服务器站点目录即可：

- `index.html`
- `styles.css`
- `app.js`

适合部署到：

- Nginx
- IIS
- 宝塔静态站点
- 任意静态 Web 服务器
- OSS / COS / CDN 静态网站托管

## 后续如果要继续改

优先改下面几个文件：

- 改文案、页面结构：`index.html`
- 改视觉风格、布局、按钮、卡片：`styles.css`
- 改账号、双语言文本、店铺数据、商品数据、图表数据：`app.js`
