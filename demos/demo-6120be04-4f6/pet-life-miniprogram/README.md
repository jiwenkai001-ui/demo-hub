# 🐾 森田宠物生活馆 · 小程序高保真原型

一个无需任何构建工具、零依赖的宠物生活馆移动端小程序原型。浏览器直接打开 `index.html` 即可运行，数据持久化在本机 localStorage。

## 功能清单

### 🏠 首页
- 门店信息卡（营业状态、评分、地址、营业时间）
- 会员权益横幅（等级、折扣、积分余额）
- 四大服务分类入口：宠物美容 / 宠物洗澡 / 宠物寄养 / 宠物用品
- 热门服务横滑卡片、用品精选网格、门店特色

### 📅 服务预约（核心）
- 服务列表 + 分类筛选（美容 / 洗澡 / 寄养）
- 服务详情：价格、会员价、服务包含项、预约须知
- 预约下单：选宠物 → 选日期（7 天）→ 选时段（含已满置灰）→ 指定美容师 → 寄养天数（寄养类按天计价）→ 备注
- 提交后生成预约单 + 订单，累计消费与积分
- 我的预约：待服务 / 已完成 / 已取消，支持取消与核销码查看

### 🛍️ 宠物用品商城（核心）
- 6 类商品筛选（主粮 / 零食 / 玩具 / 护理 / 清洁）+ 关键词搜索
- 商品详情（原价 / 会员价 / 库存 / 销量）
- 购物车：加购合并、数量增减、单选 / 全选、清空、角标
- 结算：地址选择、优惠券、积分抵扣（100 积分 = 1 元）、费用明细、实付计算
- 订单列表与详情：待付款 / 待发货 / 已完成，支持支付与取消

### 💎 会员管理（核心）
- 四级会员体系：普通 → 银卡（9.5 折 / 1.5 倍积分）→ 金卡（9 折 / 2 倍）→ 钻石（8.5 折 / 3 倍），按累计消费自动升级
- 会员卡：积分 / 储值余额 / 优惠券、升级进度条
- 积分明细、积分兑换优惠券（500 分）
- 优惠券：可用 / 已用 / 已过期
- 宠物档案：增删改（品种、性别、生日、体重、特殊备注）
- 储值充值：4 档位赠送方案
- 收货地址管理

### 👤 我的中心
- 订单入口宫格（待付款 / 待发货 / 待收货 / 已完成角标）
- 各功能入口、联系门店、退出登录、重置演示数据

## 使用方式

```bash
# 方式一：直接打开
双击 index.html

# 方式二：本地服务（推荐）
python3 -m http.server 8899
# 访问 http://localhost:8899
```

浏览器打开后按 F12 切换到手机模拟视图（如 iPhone 12 Pro, 390×844）体验最佳。

> 演示数据存储在 localStorage（键 `pet_life_store_v1`），「我的 → 重置演示数据」可随时恢复初始状态。

## 迁移到微信原生小程序指南

本原型的页面与真实小程序的对应关系：

| 原型页面 | 小程序 pages 目录 |
|---|---|
| 首页 / 商城 / 预约 / 我的 | `pages/home` `pages/mall` `pages/book` `pages/me`（TabBar 4 个，配置在 `app.json` 的 `tabBar`） |
| 服务详情 / 商品详情 | `pages/service-detail` `pages/goods-detail` |
| 预约下单 / 结算 | `pages/booking-confirm` `pages/checkout` |
| 订单列表 / 详情 | `pages/orders` `pages/order-detail` |
| 会员中心 / 宠物 / 积分 / 优惠券 / 储值 / 地址 | `pages/member` `pages/pets` `pages/points` `pages/coupons` `pages/balance` `pages/address` |
| 底部弹层 / 确认框 / Toast | 使用小程序原生 `wx.showModal` `wx.showToast` 或自定义组件 |

迁移要点：

1. **数据层**：把 `data.js` 的种子数据放入云开发数据库（集合：`services` `goods` `orders` `bookings` `pets` `members`），`app.js` 中的 localStorage 读写替换为 `wx.cloud.database()` 调用。
2. **登录**：`data-act="login"` 处替换为 `wx.getUserProfile` + `wx.cloud.callFunction` 获取 openid。
3. **支付**：结算页的「提交订单」接入 `wx.requestPayment`（需后端统一下单）。
4. **样式**：`style.css` 的 CSS 变量可直接迁移为 WXSS，rpx 换算按 750 设计稿（本原型 420px 宽 × 1.78 ≈ rpx 值）。
5. **核销码**：演示中的文字码可替换为小程序码或 `canvas` 二维码。

## 已验证的完整链路

- ✅ 登录 → 首页渲染（分类 / 热门服务 / 精选商品）
- ✅ 预约：详情 → 选宠物/日期/时段/美容师 → 提交（会员折扣生效，积分 +482）
- ✅ 商城：加购合并 → 购物车增减 → 结算（9 折 + 优惠券 -¥15 + 积分抵扣 -¥23.42，实付 ¥263.98）→ 下单（购物车核销、优惠券置已用、积分增减一致）
- ✅ 会员：等级权益 / 充值 / 积分兑换 / 宠物档案 / 地址管理
- ✅ 刷新页面数据不丢失（localStorage 与内存状态一致）
