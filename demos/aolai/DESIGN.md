# 奥莱运营管理系统 Design

## 1. 产品气质

- 定位：县域奥特莱斯商场的轻量化运营后台与双角色小程序。
- 气质：清晰、可靠、务实，带有零售运营的活力，不做炫技式大屏。
- 参考：Airtable 的企业后台信息密度与结构化操作方式，结合奥莱橙色品牌强调。
- 优先级：可扫描、少点击、状态明确、数据可信。

## 2. 色彩令牌

```css
--color-ink: #17202a;
--color-ink-muted: #5f6b76;
--color-primary: #e4572e;
--color-primary-hover: #c94420;
--color-primary-soft: #fff1ec;
--color-link: #2364aa;
--color-success: #198754;
--color-warning: #c47a12;
--color-danger: #c93c3c;
--color-surface: #ffffff;
--color-surface-subtle: #f6f8fa;
--color-surface-warm: #fffaf7;
--color-border: #dfe4e8;
--color-border-strong: #c6cdd3;
```

- 页面底色使用 `--color-surface-subtle`，内容区域使用白色表面。
- 橙色只用于主操作、关键数值、选中态和品牌标识，不大面积铺满。
- 状态色必须同时配合文字或图标，不能只依赖颜色传达含义。
- 禁止紫色渐变、深色整页背景、装饰性光球和无业务意义的背景图形。

## 3. 字体与层级

- 中文优先使用 `Inter`, `Noto Sans SC`, `Microsoft YaHei`, sans-serif。
- 页面标题：28px / 700 / 1.25。
- 模块标题：20px / 700 / 1.35。
- 卡片标题：16px / 600 / 1.4。
- 正文：14px / 400 / 1.5。
- 辅助文字：12px / 400 / 1.45。
- 数据指标：28px / 700；趋势数字使用 14px / 600。
- 字间距保持默认，不使用负字间距。

## 4. 布局与间距

- 基础间距单位为 8px，常用间距为 8 / 12 / 16 / 24 / 32px。
- PC 后台采用左侧固定导航 + 顶部上下文栏 + 可滚动内容区。
- 内容最大宽度 1440px，页面两侧至少保留 24px 内边距。
- 表格、筛选栏、工具栏采用稳定高度，避免数据变化造成布局跳动。
- 卡片圆角 8px；按钮和输入框圆角 6px；标签使用 999px 胶囊形。
- 阴影保持轻量，仅用于浮层、弹窗和悬浮工具，不为每个区块增加阴影。

## 5. PC 管理后台模式

- 导航分组：经营总览、自营货品、商户与合同、会员运营、招商管理、收银结算、物业运维、系统设置。
- 顶部展示当前商场、日期范围、通知入口、当前角色和账号菜单。
- 首页优先呈现经营总览、销售/毛利、出租率、会员活跃、库存预警和待办事项。
- 列表页统一采用：页面标题 + 说明/状态 + 筛选区 + 操作区 + 数据表格 + 分页。
- 详情页采用：摘要信息 + 主流程状态 + 分区内容 + 右侧或底部操作区。
- 重要操作使用明确的确认弹窗，危险操作必须说明影响范围。

## 6. 小程序模式

- 首屏提供角色切换：商户端 / 会员端；角色切换后使用不同的首页信息架构。
- 商户端优先：销售概览、账单对账、活动报名、报修报备、消息通知。
- 会员端优先：会员等级与积分、优惠券、活动、电子小票、停车权益、个人中心。
- 使用底部 4-5 项导航，操作入口使用图标 + 短文字，避免复杂表格。
- 移动端卡片使用 16px 内边距，触控目标不小于 44px，重要反馈使用 Toast / 状态页。

## 7. 组件规则

- 主按钮使用橙色，次按钮使用白底边框，危险按钮使用红色文字或边框。
- 图标按钮使用 Lucide 图标并提供 tooltip；有明确动作的按钮可使用图标 + 文字。
- 表格表头使用浅灰底和 12px 辅助文字，关键字段左对齐，金额和指标右对齐。
- 标签状态：正常使用绿色，待处理使用橙色，异常/逾期使用红色，草稿使用灰色。
- 图表只展示能支持经营判断的指标，统一使用橙色、蓝色、绿色和中性灰，避免彩虹配色。
- 空状态、加载态、错误态、无权限态必须有明确文案和下一步操作。

## 8. 交互与演示原则

- Demo 使用可重复的模拟数据，所有新增、编辑、筛选、确认、切换和返回操作都应有即时反馈。
- 关键演示路径必须可从首页进入并闭环：库存预警处理、商户账单确认、会员领券/积分变化。
- 所有表单在提交前做基础校验；成功后保留上下文并刷新相关指标。
- 不在界面内展示开发说明、快捷键说明或技术实现提示。
- 以“渭南奥莱”作为默认演示商场名称，数据均为虚构演示数据。

## 9. 响应式与可访问性

- PC 优先，适配 1280px、1440px 和移动端 390px 宽度。
- 不允许横向溢出、文字遮挡、按钮文字截断或动态内容导致布局跳动。
- 颜色对比满足基本可读性，表单控件有清晰 focus 状态，图标按钮有可访问名称。
