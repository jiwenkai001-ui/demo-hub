推荐演练（管理员）

  1. 商品销售：概览 → 新增销售 → 选择门店和商品 → 添加商品 → 修改数量，填写实收金额 → 保存。实收不得超过明细原价合计，差额视为折扣，分摊到各 SKU。销售、库存、订单、排行、坪效及毛利一起更新。
  2. 退货：销售分析 → 销售订单与补录 → 详情查看出库单 → 退货退款。库存退回、余额返还、消费积分撤销，原销售记录保留并标记退款。退款为整单；换货可通过“整单退款 + 新销售单”演示。
  3. 会员：销售分析 → 会员管理 → 新增会员 → 充值；开单选择相同门店的会员和“会员余额”，观察余额与积分。会员详情展示消费/充值/退款流水。
  4. 外部汇总：新增销售 → 选择“外部销售汇总补录” → 填金额、订单数和来源。新增会员数需提供相应的姓名、手机号，系统实际建档。补录可编辑和冲销。
  5. 采购补货：出入库 → 采购入库 → 新建采购单，添加一个或多个商品和成本 → 审核入库 → 登记部分付款 → 在店铺管理的财务结算中查看应付余额及核销。
  6. 门店调拨：出入库 → 店铺调拨 → 新建申请 → 通过 → 发货 → 确认收货。审核预留源店库存；发货形成在途；收货增加目标店库存。每个状态只能执行一次。源店负责审核与发货，目标店负责收货。
  7. 盘点与其他出库：库存查询 → 盘点，输入实盘数量和差异原因；“新增出库”可选择商品销售或报损/领用。报损等其他出库只调整库存。
  8. 资料维护：商品档案可维护颜色、尺码、条码、售价、默认成本与各店安全量。已有历史的商品只能停用，未使用商品可删除。SKU 建档后不可更改，新增规格用新 SKU。
  9. 备份：店铺管理 → 数据与备份 → 下载 JSON。恢复先校验版本、字段、引用、单据、余额及账本一致性，再确认替换；不合法的备份不应用。
  10. 角色与双语：退出后用 B 店店长登录，查看范围及操作差异；切 EN 检查相同业务页面。

数据与统计规则

  • 金额输入最多两位小数，账本金额按整数“分”存储；库存、订单数、新增会员数使用整数。折扣按明细原价比例分摊，并处理余分，保证明细之和等于实收。
  • 商品销售产生销售记录、出库单、库存流水；会员消费还产生储值/积分流水。其他出库不产生收入。采购审核才入库并产生应付，付款只核销已入库采购单。
  • 外部销售汇总补录表示外部渠道已经结算的汇总，保留原 Demo 的汇总录入能力。它影响销售额、订单和客单价，不重复扣本地库存，也不计商品排行、销售件数及商品毛利；不能使用本地会员余额收款。相同门店、日期、金额、订单数和来源的有效补录会拦截重复提交。
  • 商品销售令牌防止同一表单重复提交；调拨、采购审核及退款通过状态检查防止重复执行。重新开一张不同令牌的商品销售单代表新交易，不自动判断它与历史销售是否为同一张外部小票。
  • 退款日生成退货单并撤销会员资金与积分；销售分析按原销售期间剔除已退款销售，不是按退款日另记负收入。会员建档是真实独立记录，销售冲销不删除会员。
  • 本月同比/环比以截至今日的相同天数比较；历史月份使用完整月份。零基数显示“—”。门店周对比按月内 1—7、8—14 等七天分组，不跨月，合计等于选月销售额。
  • 月份作用于销售统计、销售订单及新增会员指标；库存、调拨、采购、单据和出入库流水展示当前库存或全日期业务账本，避免隐藏仍待处理的旧单。列表搜索不改变统计看板的全范围口径。
  • 可用库存 = 实物库存 − 已审核待发货调拨预留；在途不计入任一门店实物库存。盘亏与普通出库不能消耗预留数量。
  • 入库按采购成本或当前移动平均成本计价；商品销售记录当时成本，退款按原销售成本退回。流水按记账顺序计算成本；回填业务日期改变报表归属，不追溯重排已结算成本。单件成本显示取整到分，库存价值与逐件显示乘积可能出现少量舍入差。
  • 商品毛利 = 有效商品销售实收 − 对应销售成本；汇总补录不计毛利。周转天数是“当前库存成本价值 ÷ 本期日均销售成本”的估算值，不是完整期间平均库存会计指标。租金是门店设置资料，不自动生成费用凭证或净利润。
  • 预警按“安全量 − 实物库存”的缺口由大到小排列；安全量上方的缓冲区在门店设置调整。达标时显示“已达标”，超过目标才显示“超额”。

演示范围

这是可离线操作的浏览器本地业务 Demo。收款、充值、退款与供应商付款均为本地记账，不连接真实支付、银行、短信或 ERP。

账号密码使用摘要保存，页面和业务操作均检查角色与门店，会话八小时失效，同源标签页登录/退出同步。由于所有数据和校验代码都在浏览器，能修改开发者工具或本地文件的人可以绕过控制；这不等同于服务端安全鉴权或正式多用户系统。

业务成功后才整体保存账本；写入失败不应用变更。支持 Web Locks 的浏览器会序列化同源初始化和业务写入，其余环境只做版本冲突检测。该机制适用于本地演示，不提供跨设备数据库事务、后台并发控制、恢复日志或生产 SLA。清理站点数据会删除业务，需定期备份。

条码功能支持手输、粘贴或键盘式扫码枪输入条码/SKU；没有摄像头扫码。验收使用模拟文本输入，未连接真实扫码硬件。折扣采用手工实收金额，不包含优惠券、满减规则引擎、税票、部分退货、多币种或完整财务总账。
