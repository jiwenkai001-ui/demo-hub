# 嘉禾农业集团供应链 Demo

2026-11-26 · Codex

嘉禾业务工作台包含销售、采购、库存、分拣、配送、资质、报价、对账和经营报表。内置 60 家演示客户、45 家供应商、6 名录单员、2,040 个 SKU 和 346 张初始销售订单。

## 打开演示

1. 解压完整文件夹，双击 `启动演示.cmd`，浏览器会打开经营总览。 [本机演示地址](http://127.0.0.1:8126/)
2. 保持预览窗口开启。从后台右上角可打开客户订货端和供应商端。
3. 同一浏览器内使用同一个站点地址。操作自动保存在本地，系统设置支持备份和恢复演示数据。

双击入口使用 Windows 自带 PowerShell 提供本地静态文件。其他环境可把 HTML 和 `assets/` 放在同一个静态站点。已装 Node.js 的电脑也可运行 `npm start`。

## 演示顺序

1. 在「AI 智慧录单」选秦岭保障一队食堂的手写样例，点击「模拟识别」。将「洋山芋」匹配为「黄心土豆」，勾选「记住叫法」，确认并生成订单。
2. 点击「识别同客户补单」再次识别，观察「记忆命中」。队列还含表格、可播放语音、系统摘录，支持加入自填或 UTF-8 文本表格消息。
3. 在订单详情打开「客户格式打印」，核对品名「马铃薯」、单位 `KG`。在利客模拟推送中可先点「模拟失败」，再点「重试推送」取得回执。
4. 在这张订单点击「采购」。前往「采购管理」，从关联采购单打开各自的「供应商作业」，确认接单并生成送货单，回后台验收入库。
5. 各采购单入库后，在「分拣管理」输入实称数量并出库。到「配送管理」选择次日 `2026-11-27`，操作发车和签收。
6. 在「对账结算」分别生成客户应收和供应商应付，确认、登记结算。在「经营报表」查看实际生成的金额、库存流水和录单统计。

## 演示数据与环境

- 企业微信、AI 识别和利客推送使用本地模拟。语音为本地生成的普通话样例，表格与手写原单为模拟内容。客户和供应商名称、价格、单据均为演示数据。
- 日期固定在 `2026-11-26`。采购收货生成批次，分拣按实称出库。客户成交价、品名和单位以订单保存时为准。
- 浏览器存储以站点和设备为单位。供应商与客户切换用于演示不同视角，正式部署需要服务端权限与跨设备同步。访问统计在演示环境关闭。
- 正式对接需准备企业微信会话授权、利客写单接口、识别服务和实际客户打印模板。
