### 计时复现已修正

- 叫号后7分钟重呼，下一位预计仍为1分钟，不回涨到8分钟；再过3分钟完成，累计服务统计为10分钟。
- 多次过号/召回的服务段累计，过号等待不计入服务。
- 开启到场确认时，待到场不计服务时长；确认到场后开始，重呼不重置。

### 回归过程中修复

- 修正英文320px首页因按钮最小宽度产生的横向溢出。
- 服务正常关闭时等待活动请求完成，避免Windows测试清理临时数据库时仍被请求线程占用。
- 顾客取消后按钮显示冷却，避免连续重复请求；语音开关及续租串行处理，避免快速点击留下错误开关状态。
- 刷新队列时保留搜索输入焦点；实际服务分钟、撤销过期状态随同步更新。

## 操作规则与范围

| 项目 | 当前规则 |
|---|---|
| 到场确认 | 默认关闭；门店设置可开关，当前正在接待时禁止改变模式 |
| 完成并叫下一位 | 确认当前/下一位号码后提交；没有下一位或号码变化则整笔拒绝；保留单独完成/叫号 |
| 撤销 | 仅独立过号/完成，15秒内、版本正确且本店无后续业务写入；撤销空档不计服务 |
| 取消 | 仅本人等待/过号，可由门店禁用；取消30秒后才能重新排队 |
| 已到店 | 只作店员待办提示；不插队、不自动占用当前接待 |
| 语音 | 默认静音；每店租约12秒，开启页4秒续租；关闭可立即交接，页退出最迟租约过期后接管 |
| 署名 | 本浏览器可填接待员署名，仅操作记录，不代表独立账号/权限；真实角色与多窗口未实现 |
| 统计 | 等待=取号至首次叫号；服务=实际服务段累计，默认模式从叫号开始；过号占比=筛选结果中过号次数>0的号单数/筛选总数 |
| 日期范围 | 最多相差366天；档案分页与全量CSV使用相同筛选 |
| 历史时长 | V2.1及更早记录没有全部服务段数据，迁移保留其原有末次叫号至结束估算，无法追补准确历史时长 |
