# 萌宠农场重构版：修复与功能对照说明

交付日期：2026-10-22。依据为父目录的《业务与功能详细说明》V1.1和原始Demo快照。原始快照与分析文档不被新版覆盖；本说明描述新实现，原文的缺口结论仍对应原版。

## 1. 重构范围

保留四个主栏目和27个子页面原有的业务内容与入口，使用统一数据模型重新实现。页面合并或位置调整以方便操作为目的，例如“疫苗记录”纳入按宠物区分的健康档案，仍可查看、登记和编辑，并扩展到驱虫和体检。

界面采用森林绿、奶油白与暖橙配色，本地动物和商品插画、统一图标、响应式卡片、侧边导航、手机底栏与原生模态弹窗。每次仅渲染一个主路由内容，避免收藏覆盖商品详情等多层页面冲突。

## 4. 统一计价规则

原版未明确的规则采用以下演示默认值，并在页面显示，不作为真实门店的经营政策。

### 活动与订单金额

| 规则 | 默认实现 |
|---|---|
| 成人 / 儿童票 | 萌兔39 / 19元，狗狗59 / 29元，猫咪88 / 44元；儿童需成人陪同，适合3岁以上 |
| 携宠 | 关联用户宠物档案，不额外收费，不影响入场人数计数 |
| 活动会员价 | L1 9.5折、L2 9折、L3 8.5折、L4 8折；总原价折扣一次四舍五入到分 |
| 计算顺序 | 原价 → 活动会员折扣 → 一张优惠券 → 积分抵扣 → 运费 |
| 券门槛 | 按会员折扣后金额判断；范围、到期日、周三条件和使用状态必须同时满足 |
| 积分抵扣 | 100分=1元，即1分抵0.01元，最多为券后金额20%，不抵运费；负积分余额不可继续抵扣 |
| 配送费 | 快递原商品金额满99元免运费，否则8元；自提免费 |
| 预占 | 提交待付订单即占库存 / 场次 / 房间 / 技师 / 免费体检次数，同时占券及扣减抵扣积分，15分钟超时释放 |
| 支付奖励 | 实付不含运费，每满1元增加1成长值；消费积分为实付元数×付款时等级倍数，向下取整 |
| 会员日 | 每周三消费积分额外乘2，与等级倍数叠加；5元会员日券也仅周三可用 |
| 退款 | 返还库存 / 资源、券和抵扣积分，扣回原订单实际奖励与成长值；已消费奖励不足时允许积分暂负，不额外补发 |

示例：L2预约狗狗活动2成人1儿童，原价147元，会员减14.70元，使用活动券减10元，再抵1256积分（12.56元），应付109.74元。订单保存整套金额快照，后续升级不会改写历史实付或退款奖励。

### 容量、库存与服务

- 活动按场地同时在场人数校验：例如萌兔09:00—11:00和10:00—12:00共用15人空间，不能各自独立卖出15人。新时段与已有区间发生重叠时，按重叠段的最大占用人数扣位。
- 原6个起始时段保留：09:00、10:00、13:00、14:00、15:00、16:00。结束时间按活动时长计算，不把不同活动统一为2小时。
- 所有商品初始化40件单件库存；双件装按2件扣库存，价格为标准装2倍；购物车中的同商品不同规格共同校验库存。普通购物车本身不占库存，创建待付单后才预占。
- 寄养标准间80元 / 晚、4间；豪华间128元 / 晚、2间；VIP套间198元 / 晚、1间。最短1晚最长30晚，退房日不占房；同一宠物不能重复预约重叠寄养日期。演示提前退房仍按原预约日期保留房间配额，避免演练改变其他订单的既定房态。
- 美容基础洗护68元 / 60分钟、精致美容128元 / 90分钟、SPA158元 / 90分钟、药浴198元 / 90分钟。当前为统一项目价格，未引入体型加价；可选择小林、小陈、阿乐，09:00、11:00、14:00、16:00时段，同一服务人员在同一时段不能被洗护与体检重复预约。
- 体检单次128元；L3每季1次、L4每季2次免费。按服务日期所属自然季度计算，待支付也占权益；取消、超时或退款可归还该笔权益。免费体检不再叠加券与积分，实付0元也通过演示收银台完成确认。

## 5. 状态与异常处理

| 业务 | 状态流转 | 主要限制 |
|---|---|---|
| 活动 / 美容 / 体检 | 待付 → 已付待使用 → 核销完成 → 评价 | 专属券只核销一次；活动与服务提前24小时可退款，活动还可改期 |
| 寄养 | 待付 → 已付待入住 → 核销入住 / 寄养中 → 照护记录 → 退房完成 → 评价 | 核销入住不会直接完成订单；照护日期须在入住至退房前一日之间 |
| 快递 / 自提 | 待付 → 已付待发货 / 备货 → 已发货 / 备好 → 确认收货 / 提货 → 完成 → 评价 | 商家步骤在折叠演示工具内，用户步骤使用正常订单按钮 |
| 取消与超时 | 待付 → 已取消 | 回滚该订单预占的所有资源和优惠；重复取消拒绝 |
| 商城退款 | 已付未发货 → 已退款 | 发货后先进入退货处理中，演示确认退回后才退款与恢复库存 |
| 支付失败 / 取消 | 保持待付，记录本次失败 / 取消结果 | 不清车、不奖励、不生成有效券，可在15分钟内重试 |
| 领养 | 待审核 → 通过 / 未通过 → 已领养 → 回访 | 不可跳过审核直接领养；同一宠物不能重复有效申请 |

已完成的订单不在此Demo中提供普通退款入口，真实长期售后、分次退款和争议处理需服务端规则。演示工具允许模拟未来预约提前核销 / 入住及提前退房，便于现场演练，不代表真实门店可跳过服务时间。

异常值不会只依赖按钮禁用：业务方法会再次检查日期、号码、人数、时段、余位、库存、关联对象、优惠资格和当前状态。页面价格预览对超大或非法输入作显示保护，提交仍拒绝不合法值。

本地写入采用“读取最新快照 → 克隆 → 全部校验和修改 → 单次保存成功 → 发布新状态”。验证失败或空间不足不提交半成品。浏览器之间提供存储事件同步，但没有跨进程原子锁，不能用于真实多人抢购。

## 6. 内容、健康和用户经营

### 社区与知识

帖子正文5—2000字，评论1—500字，最多3张JPG / PNG / WebP图片，单张原图限8MB，保存前压缩为本地JPEG。上传重绘保留正文；成功发布才奖励10积分。点赞、关注、评论、图片、话题与分类都保存。

原帖的历史评论数保留为明确标注的热度计数，实际保存的评论单独列出，不伪造几十条可见评论。详情、列表与刷新后读取同一份记录。当前演示仅有一个账户，自发帖子首次被当前演示点赞时演练一次获赞积分，反复取消 / 点赞不重复记奖；真实多用户点赞归因需要账号服务。

知识文章各有独立ID和正文，第一次打开时本地阅读数加1，同账户重复打开不重复计数，点赞与收藏按文章保存。

### 宠物与健康

保存昵称、物种、品种、性别、出生日期、体重、绝育、芯片与头像。芯片非空时不能重复；出生日期不能在未来。新增档案+20积分，编辑不重复奖励。

疫苗、驱虫、体检记录保存机构、类型、名称、本次和下次日期、批号、说明与凭证。实际日期不能在未来，下次日期须晚于本次；新增疫苗+10积分，编辑不重复奖励。体重历史按日期保存，同一天新增体重会覆盖该日记录，当前体重取最新日期值。

同一宠物、类别与项目类型的提醒采用最新实际记录；下次日期距今7天内或逾期时生成消息。新计划不会继续沿用旧接种计划催办。提醒是页面内计算，不是微信订阅或系统推送。
