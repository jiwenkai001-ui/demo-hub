# 京麦源业务演示设计规范

日期：2026-11-17；执行者：Codex。

本文件是本项目唯一设计约束源。用户已确认方案，进入实现与本地验证阶段。

## 设计目标与参考

- 产品：西安京麦源食品有限公司业务管理演示，包含电脑管理后台及客户订货端。
- 用户已选择：清爽蓝白企业后台，表格和业务流程清晰。
- 参考 `C:/Users/kevin/.codex/skills/design-md-skill/designs/airtable/DESIGN.md` 的清晰表格、白色界面、蓝色操作与分层信息；按中文业务后台调整密度，不使用参考品牌名称、字体或资产。
- 食品行业特征通过产品名称、规格、批次、配送线路与业务数据表达。

- 页面标题 24px/600，区块标题 16px/600，正文及表格 13–14px，辅助说明 12px。
- 金额、数量和指标使用等宽数字；金额默认人民币，清晰显示单位。

## 全局布局

- 管理端：左侧品牌与分组导航，顶部面包屑、角色切换和客户订货入口，主体按统一边线排列。
- 首页展示经营指标、趋势、区域回款、待办和库存预警，指标可跳转到带筛选条件的明细。
- 列表页统一为标题与主操作、指标摘要、筛选条、表格与分页。
- 复杂编辑使用宽弹窗或详情抽屉；底部操作固定为取消、保存或确认。
- 客户端：适配手机的商品目录、购物车、订单、账单与额度页面；电脑可切换至手机宽度预览。
- 业务数据使用真实语义演示记录；所有数值从统一数据状态计算，不能写死成互相矛盾的指标。

## 基础组件

- 统一主题入口维护颜色、字号、间距、圆角、阴影和组件高度。
- 标准输入框及按钮高度 36px，紧凑表格操作 28px，手机主要操作不低于 44px。
- 间距采用 4/8/12/16/24/32px；按钮与输入圆角 6px，面板 10px，弹窗 12px。
- 表头浅灰蓝底，表格行高约 48px，数字右对齐；长表格在自身容器内横向滚动。
- 主按钮为蓝底白字，次按钮白底细边框，危险操作使用明确文案和危险色。
- focus 显示清晰蓝色外环；禁用项需说明不可操作原因，不只降低透明度。
- 状态通过颜色与文字同时表达，统一订单、库存、欠款和额度状态标签。
- 重复出现的筛选区、表格区、弹窗底部、指标摘要和空状态复用公共组件或公共样式。
- 不在业务页面覆盖组件库基础类；页面样式仅负责布局、密度及业务场景。

## 业务页面模式

| 模式 | 页面与关键呈现 |
| --- | --- |
| 经营总览 | 指标、趋势、待办、区域汇总，支持进入明细 |
| 客户档案 | 搜索与分类、客户详情、专属价格、促销、欠款、信用及区域线路 |

| 订单与录单 | 商品明细编辑、库存与额度提示、文本识别确认、损耗登记 |
| 配送与打印 | 线路筛选、品项汇总、司机配货单与送货单预览 |
| 仓储台账 | 原料与成品、批次、分次入库、出库、盘点差异与报损 |
| 生产与成本 | 原料批次领用、产出、倍率与单位成本、双向批次溯源 |
| 财务对账 | 日/月/账期、客户/区域、应收与收款、历史对账及导出 |
| 额度权限 | 超额锁单、经理临时额度与期限、角色操作说明与记录 |
| 客户订货 | 自身专属价格、促销、复购、购物车、订单与账单 |

## 交互与反馈

- 所有主操作需有实际状态结果，禁止只有提示文字而无数据变化。
- 表单显示必填项、数量单位、金额与约束；错误定位到具体字段。
- 库存不足与信用超额需显示计算依据；保留表单内容，允许修正后重试。
- 文本识别需呈现待确认明细，未匹配产品和数量不明确的内容需人工确认后入单。
- 确认提交后给出订单号、入库单号或收款记录等可追踪结果。
- 演示重置需二次确认；局部保存、导出、打印状态反馈一致。
- 不使用无目的装饰动画；提示、抽屉和弹窗动效约 120–180ms，尊重减少动态效果设置。

## 响应式与打印

- 1440px 为主要桌面验收宽度，兼顾 1280px、1920px；窄屏管理端使用折叠导航。
- 客户端主要验收 390px/430px，购物车结算区不能遮挡最后一项内容。
- A4 打印使用白底黑字、公司信息、单号、客户、线路、日期和签收栏。
- 送货单可切换单价、金额显示；无现货明细不出现在送货单，界面需提示被隐藏项目。
- 配货汇总按同一商品及规格聚合，打印列与屏幕汇总保持一致。

## 验收要求

- 本地浏览器截图检查桌面与手机布局、表格、弹窗、错误反馈和打印预览。
- 检查同一组件在各页面的尺寸、间距、状态与交互是否一致。
- 本地与预览环境统计默认关闭；正式域名配置完整时才允许加载统计脚本。
