# 育苗苗生鲜 · 信息化 Demo 现场演示讲稿

> 配套文件：`育苗苗生鲜-信息化演示Demo.html`（单文件、零依赖、离线可用）
> 使用角色：软件厂商销售 / 售前　｜　场景：上门演示 / 微信发文件给客户

---

## 一、演示前准备

1. **打开方式**：双击 HTML 文件，用 Edge / Chrome 打开即可；无需联网、无需安装任何插件。
2. **投屏比例**：建议 16:9，分辨率 1920×1080 或 1366×768；浏览器缩放保持 100%。
3. **手机演示**：点右上角「手机预览」按钮，进入手机框；或把 HTML 文件直接发微信给客户点开。
4. **顶部标识**：右上角常驻「演示数据 · 非真实经营数据」——开口第一句就要说明，避免客户误读数字。
5. **要背下来的 5 个关键数字**（都来自客户需求原文，客户一问就能答）：
   - **40 所**学校（24 所中小学 + 16 所幼儿园），执行**两套协议价**
   - **18 家**供应商，SKU **2000+**，月营业额约 **300 万**，年营收近 **4000 万**
   - **10%** 订单需内部代下单，其余客户在商城 APP 自主下单
   - 人员：**业务对接 2 人 + 入库录单 2 人 + 财务 1 人**
   - 食安资料收集时段：**18:00 – 次日 01:00**，**04:00** 出车

## 三、逐页讲解要点 + 关键话术

### 1. 经营驾驶舱
**看点**：当月销售额、年度累计、应收/应付 + 趋势折线 + 客户结构 + 品类占比 + 推荐动线。
**话术**：「这一屏就是把您现在最头疼的经营数据,一屏看到底——月销售、应收、应付、毛利结构,不用再等财务手工拉表。数据按您给的实际口径构造:40 所学校、两套协议价、约 300 万月营收。」
**反问**：「您现在想按学校看毛利,财务大概要多久才能拉出来?」

### 2. AI 智慧录单（痛点 #1）
**看点**：左侧模拟纸质送货单，右侧点「拍照并 AI 识别」→ 自动提取品名/规格/数量/单价/**生产日期/保质期** + 置信度。
**操作**：点左侧绿色按钮「拍照并 AI 识别」。
**话术**：「供应商的纸质送货单,拍一张照,品名、数量、单价,连生产日期和保质期一起提出来,您的入库人员只做确认。原来 2 个人累到加班的活,现在核对一下就行。还能对接您现有蔬东坡的 API,不用推倒重来。」
**反问**：「现在退换货、调拨反复核对单据,是不是最耗这几位同事的时间?」

### 3. 采购入库 / 调拨（痛点 #1 延伸 · 校验演示）
**看点**：调拨单默认数量 9999，点「提交调拨」→ 红色拦截「超出可用库存,无法提交」。
**操作**：保持默认 9999，点提交；再把数量改成 100 提交，展示通过。
**话术**：「调拨、退货最容易出错的就是超量。系统按实时可用库存硬校验,填多了直接拦下来,不用事后反复对账。」

### 4. 食安资料中心（痛点 #2）
**看点**：微信群消息流（18:20 / 19:05 / 21:10 / 22:48 / 00:35 上传合格证、检测报告），点「AI 立即抓取并打印」→ 资料自动进表、标记已打印、待审核。
**操作**：点「AI 立即抓取并打印」。
**话术**：「每天下午 6 点到凌晨 1 点,供应商在群里发合格证、检测报告,现在要人肉下载、打印、整理,1 点前收齐,4 点就出车。AI 自动盯群、自动抓、自动连 IoT 打印机,您的人只做审核和分配。」
**反问**：「这块现在是几个人在盯?凌晨收资料是不是特别赶?」

### 5. 协议价与价格异常预警（痛点 #3 · **核心交互**）
**看点一（数据联动）**：点「幼儿园协议价」→ 协议价、折扣、单价、销售额、毛利、毛利率**全部实时重算**；再点回「中小学协议价」对比。
**看点二（风险拦截）**：把「销售单价」手动改成 `1.00`（低于成本）→ 红色「价格异常预警……禁止保存发货」+ 保存按钮置灰。
**操作**：先切等级看联动，再改价看拦截。
**话术**：「两套协议价系统自动带出,切一下客户等级,单价、折扣、毛利立刻重算,不用手工维护、也不容易录错。万一真录了个低于成本的价,系统当场预警、直接拦住,避免亏本发货——这正是您说的负毛利风险。」
**反问**：「之前出现过录错价、亏本发货的情况吗?一笔亏多少?」

### 6. 经营分析报表（痛点 #4 · **核心交互**）
**看点**：维度切「按学校 / 按商品」，颗粒度切「每日 / 2-3 天 / 周」，可筛选单个学校；下方毛利净利明细 + 合计行。
**操作**：点「按商品」，再点「每日」，感受口径即时切换。
**话术**：「按学校、按商品两个维度,采购价、销售价、单品毛利、净利润全都有;颗粒度日/2-3天/周随您调,用来调价最快。财务 1 个人也不用手拉表了,系统自动出,最低一周一次的要求轻松满足。」
**反问**：「如果每天早上能看到昨天的单品毛利,您调价会不会更及时?」

### 7. 商品库（含产品图片 + 价格波动趋势）
**看点**：SKU 明细每行带对应产品图片（内置 SVG 图标）；下方「采购价格波动趋势」可选商品、按天/按周切换，标注当前成本、区间最高/最低、波动幅度。
**操作**：选「土豆」看按天波动；切「按周」；再选「食盐」或「冻鸡翅」——提示"价格长期稳定"。
**话术**：「商品库每个 SKU 都配了图片,库管一看图就知道是哪样货。价格趋势这块正好对上您的情况:蔬菜、水果、肉蛋按天/按周波动,冻品和调料长期稳定——系统把采购价轨迹留下来,协议价维护就有基准,不会再凭感觉录价。」
**反问**：「您现在每周调协议价,是不是主要靠经验和微信群报价?」

### 8. 订单管理（详情穿透 + 退换货）
**看点**：订单列表点任意一行→右侧抽屉打开订单详情：客户、下单方式、状态、商品明细（规格/数量/重量/单价/金额）+ 应付/已付/待付；「退换货单」标签展示客户退货/换货记录。
**操作**：点第一行「SO-20261107-0186」，展示明细与收付款；关掉后点「退换货单」标签。
**话术**：「订单一点就穿到底——每个学校订了哪些品、多少份、多少公斤、什么单价、多少钱一目了然;右边应付、已付、待付三笔账清清楚楚,月结对账不用再翻单。客户退换货也单独登记,退货原因、金额、状态全程留痕。」
**反问**：「现在客户打电话改单、退货,您这边是怎么记录和核对的?」

### 9. 采购入库（退换货单）
**看点**：右侧「退换货单」标签，展示供应商采购退货/换货记录（往来单位、商品、数量、重量、金额、原因、状态）。
**话术**：「供应商那边退换货也在这统一管理,和给学校的退货分开,避免两边搞混、反复核对单据——这正是您说的入库人员负荷大的根源之一。」

### 7. 对账管理
**看点**：客户应收账龄分桶（未到期 / 逾期 31-60 / 61-90 / 90+）、供应商应付对账。
**话术**：「客户和供应商两条对账线分开管,账龄自动分桶,逾期一眼看到,月结不用再逐笔翻单。」

### 8. 私有化与品牌（痛点 #5 · 收尾）
**看点**：改「软件名称」输入框 → 下方登录页标题实时变化；右侧替换旧系统能力对比表。
**操作**：把软件名改成客户公司名，展示实时生效。
**话术**：「私有化部署,软件名称、Logo 都能换成您自己的品牌,源码交付、支持二次开发。旧系统服务快到期,可以先对接它现有 API 平滑过渡,再逐步切过来。」

## 附：演示数据说明

- Demo 内所有数字均为**仿真构造**,仅用于呈现功能与口径;
- 客户名称采用真实的西安学校/供应商类型命名以增强代入感,但联系人、电话均为虚构;
- 数据集中放在 HTML 文件开头的 `DB` 对象中,现场可按客户真实数据快速替换;
- 已校验:账龄分桶合计=应收合计、客户类型占比=100%、品类占比=100%、汇总表合计=明细之和、完成率口径一致;订单明细金额合计=订单金额、应付=已付+待付、价格曲线末点=当前采购成本、数量×规格=重量。
- 产品图片为内联 SVG 手绘图标（离线可用,无需联网加载图片）;价格趋势按蔬果肉蛋波动、冻品调料稳定的业务规则生成。
