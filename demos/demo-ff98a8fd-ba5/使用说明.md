# 装修公司管理系统（纯前端演示版）

> 界面采用清新装修风：薄荷绿主色搭配珊瑚橙/沙金色色卡，融入户型网格、施工图纸纹理与色卡条等家装设计元素。

## 一、界面入口

| 文件 | 说明 |
| --- | --- |
| `index.html` | 系统入口页，可跳转到管理端与业主端 |
| `pc.html` | PC 管理端后台（建议电脑浏览器使用） |
| `mini.html` | 业主客户端小程序（手机尺寸界面，电脑浏览器也可直接体验） |

## 二、功能模块

### PC 管理端
- **工作台**：在建项目、待确认方案、未读消息、本月收款、收款趋势、项目进度概览、待办与公告
- **客户管理**：客户建档、意向等级、来源追踪、详情（关联项目与需求备注）
- **项目管理**：项目卡片、施工阶段流程条、进度条、项目详情（进度记录/方案/款项）
- **施工进度**：项目进度总览、施工日志时间轴、现场照片记录、进度更新（自动同步项目阶段与进度）
- **方案管理**：平面方案/效果图/施工图/概念方案上传、版本管理、确认状态、客户反馈
- **沟通消息**：按项目查看对话、切换项目、以设计师/项目经理/监理身份回复
- **报价款项**：报价单明细与合计、款项节点、确认收款与待收款统计
- **材料管理**：材料品牌规格、数量单价、供应商、待采购/已到场状态跟踪
- **团队管理**：设计师、项目经理、工长、监理资料与负责项目数
- **报表统计**：项目状态分布、团队接单量、客户来源、收款构成
- **系统设置**：公司信息维护、数据导出、演示数据重置

### 业主客户端小程序
- **首页**：项目概览、快捷入口、待确认方案提醒、我的项目、公司公告
- **进度**：切换项目、阶段流程、总体进度、施工日志时间轴与现场照片
- **方案**：按项目与状态筛选方案、查看详情、确认方案、填写修改反馈
- **沟通**：家装服务群聊、快捷回复、发送消息（同步到 PC 端）
- **我的**：业主信息、功能入口、切换项目、关于我们、数据重置

## 三、使用说明

1. 用 Chrome 或 Edge 打开 `index.html`，选择进入管理端或业主小程序。
2. PC 端登录页输入任意账号密码即可进入（已预填 `admin / 123456`）。
3. 两端数据共享基于浏览器 `localStorage`。**通过同一个本地服务器或同一浏览器的 file:// 打开时两端数据互通**；若浏览器安全策略限制 file:// 源，可能各自独立。
4. 在 PC 端「系统设置 → 导出全部数据」可下载 JSON 备份；「重置为演示数据」可恢复初始状态。
5. 演示数据包含 6 位客户、6 个装修项目（设计中/待开工/施工中/已完工）、施工日志、设计方案、沟通记录、报价与款项、材料清单和团队成员。

## 四、技术说明

- 纯 HTML + CSS + 原生 JavaScript，无任何第三方框架与后端依赖
- 数据持久化：浏览器 localStorage（键名前缀 `decoMgmt_`）
- 所有页面、样式、脚本均在本地，可离线运行
- 现场照片与方案效果图使用 CSS 渐变占位块模拟，无需外部图片资源
