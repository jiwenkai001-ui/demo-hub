# 功能保留与修复对照

依据：上级目录《业务与功能详细说明》V1.1、留存的原 `src/App.vue`、`src/mock.ts`。本文件描述**新演示版**，不修改原分析对旧 Demo 的结论。

## 原功能入口保留

| 原模块 / 功能 | 新版入口与处理 |
|---|---|
| 经营总览、日报、销售/客流趋势、商户排行、会员洞察、提醒 | 经营总览；补独立到访记录、真实统计及单位切换 |
| 自营货品、查找筛选、新建、预警处理、详情、调整 | 自营货品；预警处理对应“补货”，补采购审核、双仓调拨及盘点流水 |
| 商户新增、查找、账期切换、详情、对账及经营报表 | 商户与合同 → 商户合同 / 账单与缴费；确认、分次到账与开票相互关联 |
| 会员搜索、高价值/沉睡分群、详情、定向券、活动、月报 | 会员运营 → 会员档案 / 营销活动 / 权益与核销 |
| 运营协同四模块及刷新 | 运营协同和顶部刷新；各模块保留原入口 |
| 招商品牌、阶段推进、合同审批 | 招商管理；推进后填写合同正式签约并建档 |
| 收银交易明细、退款审核 | 收银与结算；补实际收银、券、库存、积分和退款联动 |
| 物业筛选、新建、派单、处理、验收 | 物业运维；可选处理人，补退回、重开和日志 |
| 停车详情、异常处理、日报导出 | 智慧停车；补入场、会员减免、演示缴费离场及费用快照 |
| 会员手机：首页、权益、消息、我的 | 移动端演示 / 独立member登录；积分、券、小票、活动、推荐、停车、资料、安全、联系人和反馈均有内容 |
| 商户手机：首页、账单、消息、我的 | 移动端演示 / 独立merchant登录；销售、报名、报修、合同、历史账单、开票、联系人及资料保存 |
| 消息分类、单条阅读、全部已读 | 两种手机身份的消息标签；独立读标记与分类 |
| 帮助、设置、提醒、18点日报、刷新、恢复演示 | 帮助中心、系统设置、通知中心；开关生效，本地打开期间定时运行 |
| 原经营日报、商户报表、会员月报、停车日报 | 各原模块保留下载入口；新增列表导出和JSON备份 |

重构优化了布局和操作名称，保留原业务用途；原来仅弹出成功提示的功能改为可查看的记录、可提交的表单或清楚说明的演示能力。
