# 业务规则与数据说明

## 对象与关联

商品、会员、商户、铺位、销售、券实例、账单、工单、招商线索、停车记录均使用独立编号关联。新增记录置顶后，账单、手机身份和交易归属仍根据编号解析。

业务提交统一执行：检查当前演示权限 → 读取较新本地版本 → 复制状态 → 校验与修改全部相关对象 → 一次写入JSON → 刷新界面。发生校验或保存错误时回滚内存修改。不保证多标签页同时写入时的数据库级隔离。

## 商品与库存

- 双仓：门店仓、后仓。库存、安全库存、采购与调拨数量为有上限的非负整数；实际采购、调拨及销售数量必须为正整数。售价为正，成本不能为负。拒绝空字符串、Infinity、非法日期和重复SKU。
- 库存预警 = 门店数量 < 安全库存；滞销 = 距入库日期超过30天。两种标记可以同时出现，盘点或补货不会抹掉库龄。
- “处理预警”保留为补货入口，通过真实调拨或采购改变数量，不直接强制改成正常。
- 采购单先待审核，审核后入库，加权成本 =（原库存成本金额 + 采购金额）/ 新总库存。不重复审核。
- 盘点按实盘数与现有数之差登记流水。调拨一出一入，数量守恒。销售减门店库存，整单退货回门店库存。
- 台账及流水以商品/仓库级管理；当前未实现按批次的FIFO、保质期、序列号、采购付款与多供应商应付账。原系统并无这些可操作功能，本版不将库存流水冒称完整ERP。

## 合同与账单

- 铺位面积从独立铺位档案取得，不允许任意填0；同一铺位不同时签给两个未退场商户。
- 固定租金：月应收 = 月租金。保底+扣点：月应收 = max（月保底租金，账期净销售 × 扣点比例）。输入百分数统一换算为小数。
- 账期切换实际过滤该月销售与账单。账单是生成时快照，生成缺失账单不覆盖已有记录；生成后新增销售、退款不静默改写已确认账单。
- 整月计费，不做首尾月按天分摊、税费拆分或跨期追补。真实上线须另行确认这些结算政策。
- 状态顺序：待确认 → 确认后待缴费 → 部分缴费 → 已结清。已确认且过期未结清显示逾期。确认不会改变商户合同状态。
- 商户只能确认本人账单；财务登记到账，金额不得超过剩余应收。结清后申请演示发票，禁止重复申请和重复开具。
- 修改合同到期日完成演示续约；退场必须先结清全部已有账单。历史合同与交易保留，不删除商户。
- 招商：初步接洽 → 方案沟通 → 合同审批 → 待签约 → 填写正式合同 → 已签约并创建商户。签约时重新检查铺位占用。

## 会员、券与交易

- 等级按累计消费动态计算：普通卡 < 2000，银卡 ≥ 2000，金卡 ≥ 5000，白金卡 ≥ 10000。高价值分群为累计 ≥ 8000；沉睡为距离最近到访 ≥ 30天。
- 期初会员累计消费已包含展示的历史销售，新收银增加累计消费，退款减少；不重复累加期初小票。会员到访登记或消费更新最近到访日期。
- 活动保存日期、人群和券模板，向符合人群的会员生成消息。活动日期必须落在券有效期内。模板若关联多个活动，会员须满足至少一个当前有效活动的人群条件。
- 每种模板每人限领一张，发放产生独立券实例、发放时间和消息。检查有效期、发行总量、目标人群、所属会员、品类、最低消费及已使用状态。
- 演示收银一次选择一种商品，可指定数量、会员和一张券。折扣券按商品金额乘折扣；满减券满足门槛后减固定金额。积分 = 实付金额向下取整。
- 收银成功同时写销售、扣库存、核销券、加积分、生成收款记录及会员小票消息。任何一步失败均不留下半张订单。
- 退货为整单退货：申请待审 → 通过后回库、冲积分、减累计消费、恢复券、写原渠道演示退款；驳回恢复已完成。过期券恢复实例状态后仍无法使用。暂不提供拆单退货、真实第三方退款和积分兑换。
- 期初历史销售对应期初库存和积分快照，退货不重复回库/冲期初积分；其退款仍影响净销售及会员累计消费。

## 工单与停车

- 工单：待派单 → 选择处理人 → 处理中 → 完成处理 → 待验收 → 验收通过 → 已完成。允许验收退回处理和完成后重开。
- 处理说明、操作人、实际时间与完成时间保存到流转日志；普通要求24小时，紧急要求2小时。今日完成按本地完成日期统计，平均耗时来自已关闭工单，验收通过率来自本版记录的验收/退回日志，无记录时显示暂无记录。
- 商户报修强制关联本人商户和铺位；不能自行派单验收。物业账号可创建和处理工单。
- 停车：车牌唯一在场，绑定会员车牌自动识别本地身份。基础免费15分钟；银/金/白金卡分别每天60/120/180分钟会员减免，普通卡0。时长先扣当日剩余会员分钟，再扣基础分钟，剩余不足1小时按1小时计，每小时默认5元。
- 离场时才消耗会员日权益并生成演示收款。未解决异常禁止离场；异常处理必须填写复核说明。离场保存时间、减免、费率计算结果，之后设置或时间变化不回算已结算费用。
- 停车入口和缴费为本地人工演示，无识别摄像头、闸机和支付接口。跨夜订单按离场当日权益结算，不做跨日拆分。

## 统计、消息、导出与重置

- 总览销售和毛利来自有效交易，退款待审尚未冲销，已退款不计；毛利为实付减销售时成本，不能理解为商场扣除租金税费后的净利润。
- 客流来自独立演示到访登记，单位人次；停车是车辆条数，单位辆，不与客流混算。切换图表同时切换数据、单位及总量。
- 商户排行按当前月净销售降序。商户收缴率 = 所选月已收 / 应收；无应收显示0。会员占比按有效交易笔数计算。
- 提醒已读与业务处理分离，全部已读不会删除欠费、库存、工单或停车异常。新业务对象的新提醒保持未读。关闭提醒仅控制运营待办面板，不会抹去业务记录。
- 手机消息按身份和目标编号筛选，保留通知/权益/账单分类与全部已读。
- 原经营日报、商户经营报表、会员月报、停车日报均可下载；另有货品、商户、会员、停车列表CSV。列表导出应用当前搜索/筛选，导出全部匹配项而非仅当前页；日期报表应用对应的日期或账期。
- CSV为UTF-8 BOM，处理引号和可能触发表格公式的内容。完整JSON备份含本机演示资料，不上传网络。
- 恢复初始演示时重建全部业务数据、通知、日志、设置及表单/搜索/筛选/分页/移动端状态；保留当前管理员登录，以便继续体验。
