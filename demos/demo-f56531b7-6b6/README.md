# 渭南奥莱运营管理系统 · 重构演示版

直接双击本目录的 **index.html**，使用 Edge 或 Chrome 打开。无需安装 Node.js、无需联网、无需编译。

这是基于原 Demo 源码和《业务与功能详细说明》V1.1 重构的独立演示系统。原分析文档、源码快照和旧系统均未覆盖。

|---|---|---|
| admin | 运营管理员 | 全部管理功能、两种移动端预览、系统设置、恢复演示 |

管理员点击侧栏“移动端演示”，可切换指定会员或商户，核对端间数据关联。独立会员、商户登录固定使用本人的编号，不按列表位置取第一条。

## 建议演练

1. **库存闭环**：自营货品 → 新建采购 → 审核入库；或商品补货 → 后仓调拨到门店。检查双仓数量和库存流水。
2. **营销与交易**：会员运营 → 定向发券 → 收银与结算 → 新建收银，选择同一会员、适用品类和优惠券。检查出库、积分、券核销及移动端小票。
3. **退货闭环**：交易申请退货 → 退款审核通过。检查回库、消费和积分冲销、券恢复、演示资金正负记录。
4. **商户财务**：商户端确认账单 → 财务登录登记部分缴费 → 结清 → 申请开票 → 财务生成并下载演示凭证。
5. **招商转入驻**：招商线索逐阶段推进 → 待签约 → 填写合同签约。自动生成商户档案，铺位重复占用会被拦截。
6. **物业闭环**：商户报修 → 物业选择处理人派单 → 完成 → 验收，支持退回和重开，保留每一步日志。
7. **停车闭环**：查看会员减免 → 处理异常 → 缴费离场；离场结果固定保存，不随之后时间和费率变化。

## 保留与改进

保留经营总览、自营货品、商户与合同、会员运营、运营协同及其招商/收银/物业/停车模块；保留会员端和商户端四个主标签及原服务入口、通知、设置、帮助、重置和原报表导出能力。

新增完整资料表单、采购审核、双仓调拨、库存流水、账单分次缴费、演示发票、真实券实例与核销、招商签约、工单退回重开、停车结算、到访登记、本地保存和演示角色权限。表格支持搜索、适用的状态筛选与分页；390像素窄屏提供可展开侧栏。

详细逐项对应见 [功能保留与修复对照.md](功能保留与修复对照.md)，业务规则见 [业务规则与数据说明.md](业务规则与数据说明.md)。

## 数据范围

- 数据保存在当前浏览器的 localStorage，登录保存在当前标签页的 sessionStorage。刷新保留业务，更换浏览器、文件位置或清理站点数据可能使存储隔离或清空。
- 同一浏览器来源内的标签页可同步刷新；不同设备、不同来源不共享数据。并发写入不具备服务端数据库事务隔离，建议单标签页执行演练。
- “导出数据备份”输出完整JSON快照；当前提供备份导出，不提供导入合并。“恢复初始演示数据”会替换本地业务记录并清理界面筛选，请先备份。
- 日期以打开设备的本地日期初始化，历史样本相对当天生成。首次初始化保存后不会每次刷新重新造数。
- 演示账号与权限属于本地交互控制，不是生产级鉴权。无服务端、真实支付/退款、税务、短信/推送、车牌硬件和后台客服。相关按钮创建可查询的演示业务记录，不向外部系统发送请求。
- 自动刷新与18点简报仅在页面打开、已登录且具有权限时运行。关闭浏览器后不执行定时任务。
