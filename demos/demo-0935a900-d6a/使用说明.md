# 视力门诊管理系统（纯前端演示版）

## 一、界面入口

| 文件 | 说明 |
| --- | --- |
| `index.html` | 系统入口页，可跳转到管理端与客户端 |
| `pc.html` | PC 管理端后台（建议电脑浏览器使用） |
| `mini.html` | 客户端小程序（手机尺寸界面，电脑浏览器也可直接体验） |

## 二、功能模块

### PC 管理端
- **工作台**：今日预约、在册患者、今日营收、库存预警、7 日预约趋势、接诊进度、热门项目与公告
- **预约管理**：新建/编辑/完成/删除预约，按患者或预约号搜索
- **患者档案**：建档、编辑、详情（含检查/消费/预约记录）、删除
- **诊疗记录**：裸眼视力、矫正视力、球镜/柱镜/轴位、诊断、处方与医嘱
- **验光配镜**：镜片、镜架、护理品、药品与服务的库存管理，低库存预警
- **收费管理**：多项目开单、金额自动计算、收款状态跟踪、营收统计
- **医生管理**：医生资料、职称、专长、挂号费、标签维护
- **报表统计**：营收趋势、预约项目分布、医生接诊量、患者年龄结构
- **系统设置**：门诊信息维护、数据导出、演示数据重置

### 客户端小程序
- **首页**：就诊人问候、数据概览、四大快捷入口、推荐医生、门诊公告
- **预约**：选日期/医生/时段/项目，提交预约，查看与取消我的预约
- **自测**：左右眼 E 字表方向辨认，5 题后给出参考结果与建议
- **报告**：按就诊人查看历史检查报告，含验光数据与医嘱详情
- **我的**：就诊人信息、功能入口、切换就诊人、门诊信息、数据重置

## 三、使用说明

1. 用 Chrome 或 Edge 打开 `index.html`，选择进入管理端或客户端。
2. PC 端登录页输入任意账号密码即可进入（已预填 admin / 123456）。
3. 两端数据共享基于浏览器 `localStorage`。**通过同一个本地服务器打开时两端数据互通**；若直接双击以 `file://` 方式打开，不同浏览器的文件源策略可能导致两端数据各自独立，此时以各自页面内的数据为准。
4. 「系统设置 → 导出全部数据」可下载 JSON 备份；「重置为演示数据」可恢复初始状态。
5. 视力自测结果仅为娱乐与初步参考，不作为医学诊断依据。

## 四、技术说明

- 纯 HTML + CSS + 原生 JavaScript，无任何第三方框架与后端依赖
- 数据持久化：浏览器 localStorage（键名前缀 `visionClinic_`）
- 所有页面、样式、脚本均在本地，可离线运行
