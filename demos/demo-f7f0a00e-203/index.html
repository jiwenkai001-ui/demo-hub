Restaurant Demo Suite

扫码点餐 + 收银双端联动演示

同一个静态项目中包含顾客点餐端与收银机 Web 端。顾客支付成功后，模拟收银打印机与后厨打印机同时出票， 且小票突出显示桌位号与流水号。

本地双击启动 / 服务器静态部署均可演示

顾客小程序端（H5模拟）

免账号密码，模拟微信手机号授权登录。支持桌号参数进入对应餐桌点餐页。

账号密码登录，实时接收订单，订单支付后自动生成收银联与后厨联，模拟双打印机同时出票。

餐桌扫码入口（演示）

请先设置一个手机可访问的演示地址，然后系统会为每个桌位生成一个通用二维码。顾客用微信或支付宝扫码都可进入点餐页。

建议使用本机局域网地址部署并打开本页，这样客户手机扫码后可直接进入点餐端。

若要手机端与收银端跨设备实时同步，请使用 py -3 serve_demo.py --host 0.0.0.0 --port 8800 启动服务。
