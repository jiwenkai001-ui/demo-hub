# 点餐双端 Demo 设计规范

## 1. 视觉方向
- 业务场景：餐饮门店扫码点餐 + 收银机出票协同。
- 气质关键词：清爽、明亮、可信、操作高效。
- 设计风格：偏 `airbnb` 的友好轻运营风格，叠加收银场景的票据工业感。

## 2. 主题变量（统一入口）
- 文件：`assets/common.css` 的 `:root`。
- 颜色：
  - 主色：`#ff6a3d`（点餐主操作）
  - 辅色：`#0b7a75`（收银确认、状态）
  - 成功：`#1e9a5f`
  - 警告：`#dc7a1f`
  - 危险：`#be2d2d`
- 基础圆角：`22px / 14px`
- 阴影：`--shadow-soft`、`--shadow-card`

## 3. 组件一致性约束
- 基础按钮统一使用 `.btn` 与变体 `.btn-primary / .btn-accent / .btn-ghost`。
- 输入类控件统一由 `.field` 承担尺寸、边框、焦点态。
- 状态标签统一使用 `.pill` 及 `tag-success / tag-warning`。
- 空状态统一使用 `.empty-card`。

## 4. 页面结构模式
- 总入口：品牌说明 + 双端入口卡片 + 餐桌扫码入口链接。
- 小程序端：登录面板（手机号授权） + 菜单总览区 + 分类导航 + 图文菜单区 + 购物车区 + 支付页。
- 收银端：登录面板（账号密码） + 实时订单区 + 双打印票据区。

## 5. 交互规则
- 小程序端登录：仅手机号授权，不展示账号密码输入框。
- 小程序端下单后进入支付页面，支付成功后才通知收银端和后厨出票。
- 收银端登录页：必须直接展示演示账号密码。
- 已支付订单进入时：同时生成收银联与后厨联票据。
- 每张票据必须显示桌号与流水号。

## 6. 响应式规则
- `>=1120px`：收银端三列布局。
- `<1120px`：收银端自动切换单列。
- `<980px`：小程序端菜单与购物车切换单列。
