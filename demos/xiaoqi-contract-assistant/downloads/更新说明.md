# 1.0.6 · 新增提前四个月提醒

更新日期：2026-11-17。

正铺和多经广告位均可选择半个月（15 天）、一个月、两个月、三个月、四个月。合同清单与提醒设置同步，按当前账号保存，立即更新清单、开始提醒日、统计及桌面白猫角标。四个月按自然月计算，月末取目标月最后一天；已续签、已撤场及已处理的排除规则继续生效。升级保留各账号原先选择的时间，可在清单上方切换为四个月。

# 1.0.5 · 可选择提醒时间

更新日期：2026-11-17。

合同清单上方新增「提前多久提醒」，正铺与多经广告位可分别选择半个月（15 天）、一个月、两个月、三个月。「提醒设置」页同步提供相同选项。选择后自动保存至当前账号，并立即重新计算待提醒清单、到期统计、明细中的开始提醒日、导出明细与桌面白猫角标；新进入提醒期的合同按原每日一次规则提示。

一个月、两个月、三个月按自然月计算，目标月份没有对应日期时取该月最后一天，不以 30/60/90 天代替。旧账号默认仍为正铺提前一个月、多经广告位提前 15 天。每个账号分别保存，调整时间不影响已续签、已撤场、正铺撤场联动及手工处理排除。

# 1.0.4 · 正铺撤场联动广告位

更新日期：2026-11-17。

同站点、同供应商、同品牌的正铺已撤场，且该商户品牌在本站没有其他未撤场正铺时，关联广告位自动归入「已撤场」，不计入待提醒、到期统计、白猫角标及消息通知。正铺实际撤场日期即使早于广告合同开始日，也按已撤场处理。独立多经点位不适用此规则。

明细显示「正铺撤场联动」原因、正铺铺号、合同编号和撤场日期，可跳转查看正铺记录；导出明细同步保留这些依据。只在传签台账出现的已通过后续正铺也会用于防止误排除。品牌或供应商缺失、身份冲突、仍有未撤场正铺时不猜测关联。

撤场关系每次按当前台账和本地手工标记重新计算，不写成永久已处理；修正撤场、取消手工标记或补入未撤场正铺后重新计算广告提醒。原有同铺号续签排除规则继续有效。

# 1.0.3 · 同铺号续签排除

更新日期：2026-11-17。

同站点、同完整铺号已有后续已通过合同后，旧合同自动标记为「已续签」，从待提醒清单、到期统计、桌面角标和消息提醒中排除。后续合同仍按自己的到期日正常提醒。

识别范围包括租费台账和合同传签台账。需有不同合同编号、有效起止日期、已通过或正常等有效状态，且后续合同开始日不早于旧合同到期日、到期日更晚。新合同已获批准但尚未开始时，也可作为后续合同依据；后续合同之后已经撤场，也保留它承接早期合同的历史事实。驳回、草稿、审批中及日期不完整、期间重叠的记录不会用于自动排除。

只比较同类资源的同站点完整铺号，不用铺号部分文字匹配，也不跨站点合并。同铺号后续承租方变更时，同样不再对更早的旧合同重复提醒。界面新增「已续签」分类，明细可查看后续合同编号、期间、供应商，并跳转到后续合同。

这项规则动态计算，不篡改平台数据、不写成永久已处理标记。后续依据被移除或不再满足条件时，旧合同按原规则重新计算。

# 1.0.2 · 白猫快捷方式与程序图标

更新日期：2026-11-17。

桌面快捷方式、开始菜单、程序及通知区域图标，以及界面中的宠物形象统一换为白猫。快捷方式使用独立的版本图标文件，避免系统继续显示缓存中的旧猫头鹰图标。程序启动后即显示桌面白猫，尚未登录时也可以点击白猫进入登录界面。

# 1.0.1 · 白猫桌面宠物

更新日期：2026-11-17。

桌面宠物已替换为用户提供的白猫图片，提取透明背景，保留蓝色项圈与毛绒细节。适当增大悬浮区域，保留提醒数量、消息气泡、点击查看合同和拖动功能。

账号、台账及提醒处理记录仍使用原有本地数据目录，无需重新导入。程序已退出时直接双击桌面快捷方式即可使用新版；程序正在运行时请先从通知区域菜单退出，再重新打开。
