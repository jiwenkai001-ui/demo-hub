# 合同小助手「小栖」

Windows 10/11，64 位。界面使用 HTML/CSS/JavaScript，桌面能力由 Electron 提供。使用便携目录中的「合同小助手.exe」，无需安装 Python 或 Node.js。

## 开始使用

1. 双击桌面「合同小助手」，或便携目录中的同名 EXE。
2. 点击「使用运营平台账号登录」。在平台原生窗口输入自己的账号、密码，按平台要求完成登录。
3. 登录后助手识别当前平台账号，自动导出并读取租费、广告位多经租管费、合同传签，以及广告位多经传签。第一次更新需要等待平台生成文件。
4. 更新成功后进入合同清单。点击「回到桌面小助手」，主界面收起，小栖常驻桌面。拖动小栖旁边的小圆点可以移动位置；点击小栖打开工作台。
5. 其他人使用时，点击工作台左下角退出账号，再用自己的账号登录。导出范围由运营平台分配的权限决定。

Chrome、Edge、搜狗等浏览器可继续照常使用。助手内置独立的平台窗口，不需要读取这些浏览器的密码或安装浏览器扩展；首次需在助手的平台窗口单独登录一次。有效的平台会话会在下次启动时尝试恢复。

## 提醒规则

- 在合同清单上方「提前多久提醒」或「提醒设置」中，分别为正铺与多经广告位选择半个月（15 天）、一个月、两个月、三个月、四个月。即选即存，按当前账号保存；清单、统计、桌面角标、明细和导出中的开始提醒日同步更新。
- 一个、两个、三个、四个月按自然月计算，目标月没有对应日期时取该月最后一天。例如 5 月 31 日到期、提前三个月，则从 2 月最后一天开始提醒。
- 默认值：正铺提前一个月，多经广告位提前 15 天。旧账号升级后保留原默认。扩大提醒时间后新进入提醒期的合同会主动提醒，同一合同每天仍只主动提醒一次。
- 到期当天属于即将到期；到期后显示已到期，保留到标记处理或撤场。
- 已撤场/已退场/撤场完成等明确状态，以及已经生效的实际撤场日期，排除提醒。「未撤场」「待撤场」不会误判为已撤场。
- 在明细中手动标记「已撤场」也会排除，可在已撤场清单中取消手工标记。平台原始撤场状态需在平台修正后重新同步。
- 正铺撤场联动：同站点、同供应商、同品牌的正铺均已撤场，且没有其他未撤场正铺时，关联广告位也归入「已撤场」，不再提醒。独立多经点位不联动；跨站点、不同商户或品牌不会互相影响。身份信息缺失、冲突或同商户还有未撤场正铺时不自动排除。
- 广告明细显示关联正铺、合同号及撤场日期，可点击查看正铺；导出明细也记录联动原因。平台租费台账的有效实际撤场日期优先于传签中的旧审批状态。后续修正撤场或出现未撤场正铺后自动重算，不需永久标记已处理。
- 已驳回/已作废/已撤销等未通过审批的合同不产生到期提醒。
- 同站点、同完整铺号存在已通过的后续合同（起始日不早于旧合同到期日，到期日更晚），旧合同标记「已续签」，不再计入待提醒。后续合同自己的到期提醒照常执行。已批准的未来续签也参与识别；后续合同后来已撤场时，不会使更早的旧合同重新提醒。审批中、驳回、日期不完整或重叠的合同不作为自动排除依据。
- 「已续签」清单保留历史合同，可查看后续合同编号及起止期间。不同站点、不同完整铺号、不同资源类别不会互相覆盖；同铺号有后续承租方时，也不再对旧合同重复提醒。
- 同一合同每天首次检查时主动提醒一次。新进入提醒期的合同另行提醒；稍后提醒为 24 小时。标记「已处理」后停止提醒，到期日变化后重新计算。
- Windows 通知受系统通知设置、勿扰模式影响；桌面小助手仍显示待关注数量。电脑关机、睡眠或程序完全退出期间不执行检查，恢复运行后重新检查。

## 数据与金额

租费报表的「合同期」用于提取实际合同起止日；不把合同传签报表中的铺位旧合同到期时间误当成本次合同到期日。

普通合同的约定月费及保证金读取合同传签台账中的「拟承租条件」，不读取相邻的「租赁政策」金额。原表的递增约定同时展示；这些约定金额不冒充递增后的当前月费。租费台账按月实际计费另外展示，可能包含免租、不足整月等调整。

多经广告位合同读取广告位多经传签台账明确列示的月费；一次性总额或按期总额不会擅自换算为月费。保证金包括运营管理、公共事业等原表明细，上期已缴金额与本期金额分别展示，不相加。

优先通过合同编号关联合同。只有缺少编号且站点、供应商、铺号完整时使用备用匹配；身份信息存在冲突、多个到期日期或无法识别日期时显示待核对。没有费用记录显示「未提供」，不是零元。每笔费用可展开查看原始列名、值、文件、工作表和行号。

自动同步默认在登录后和运行期间每两小时执行。可以在「台账与更新」立即更新，也可以在「提醒设置」关闭自动同步。每次完整导出成功后统一替换快照；登录失效、权限不足、页面结构或报表格式变化时保留上次快照，并显示同步失败。请关注最后更新时间。

## 手动导入与导出

自动同步暂不可用时，可在运营平台「费用管理 → 费用收缴 → 导出」获取两类租费报表，并从合同传签台账、广告位多经传签分别导出费用报表。

在「台账与更新」选择相应台账导入。标准平台报表自动识别多行表头及全部相关工作表；普通自定义 Excel/CSV 则需要确认工作表、表头行及字段映射。自定义报表的多工作表请先整理为同一工作表后导入。

手动导入后可以跟踪源文件更新，检查间隔 30 秒。原文件移动、改名或表头变化时需要重新导入。演示样表中均为虚构数据，不会自动加入正式台账。

工作台「导出明细」生成 Excel，包含合同提醒清单和关联的费用及保证金。

## 保存与退出

本地账号数据保存在 `%APPDATA%\contract-desktop-assistant\accounts`，按平台用户标识与租户隔离。下载的原始报表也保存在相应账号目录。程序包中不内置任何人的用户名、密码或合同数据，助手不自行保存明文密码。平台自身的原生登录页及会话由平台管理。

关闭主界面会收起到桌面助手，保持后台运行。彻底退出请使用「提醒设置 → 退出整个程序」，或 Windows 通知区域图标右键「退出程序」。开机启动可以在提醒设置中开启或关闭。

## 开发与检查

源码入口：`main.js`，台账处理：`logic.js`，平台导出适配：`platform-sync.js`，界面：`ui/`。

安装依赖：`npm install`。启动：`npm start`。核心测试：`npm test`。桌面交互测试：`node tests/ui-smoke.js`。生成便携目录：`npm run pack`。

平台原生权限、页面或报表结构变化后，可能需要维护导出适配。程序不会执行合同修改、撤场提交、缴费等写入操作；手工处理和撤场标记只保存在本地助手中。
