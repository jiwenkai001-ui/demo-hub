# 本地工具模块

日期：2026-11-17；执行者：Codex。

- 这里只提供静态文件预览与本地检查，不提供业务 API，不连接外部服务。
- 静态服务仅默认绑定 loopback，正确声明 UTF-8 和常见资源 MIME，不允许路径越界。
- 检查和测试均由本地 AI 执行，禁止添加 CI；测试运行隔离于用户演示数据。
- 临时输出使用项目 `.codex-tmp/`，不得递归删除。
- `preview.ps1` 使用 TcpListener 默认 8117；`-PreviewPort` 和 `-NoBrowser` 仅供本地检查。默认启动会打开浏览器，自动测试必须加 `-NoBrowser`。
- 为兼容 Windows PowerShell 5.1 对含中文脚本的解析，该 PS1 保持 UTF-8 BOM；不要用无 BOM 的 UTF-8 覆盖。UTF-8 无 BOM 可能导致首行中文注释吞掉参数声明。
- 已在 8118 的隔离预览实例上通过真实浏览器加载后台和学校端；测试完成后仅结束对应测试会话。
