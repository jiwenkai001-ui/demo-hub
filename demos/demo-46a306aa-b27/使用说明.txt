序物 · 办公用品管理 — 纯静态 HTML 离线演示版

打开方法
1. 将整个压缩包解压到任意文件夹。
2. 使用 Edge 或 Chrome 双击打开 index.html。无需 Node.js、无需本地服务、无需联网。
3. 右上角切换演示身份，王晨/李敏/陈屿为员工，周宁为管理员。

推荐演示流程
员工添加多种物资并提交申领 → 切换周宁 → 申领审核整单通过或逐项处理 → 库存自动扣减 → 数据追溯查看出库明细 → 生成并下载月报。
管理员可在“采购入库”中多行录入或下载 Excel 模板后填写并导入，再确认入库；可在“库存台账”选择物资后批量调整。
快捷指令示例：申请打印纸2包、按动中性笔5支，用于项目会议；查一下打印纸库存；打开待审核；入库打印纸20包；生成2026年11月月报。

数据保存与迁移
操作实时保存到当前浏览器的 localStorage。关闭后使用相同浏览器、相同路径再次打开可继续使用。
不要使用无痕模式。清理浏览器数据、更换浏览器或移动 HTML 文件可能使原数据不可见或丢失。
请在一个标签页内演示，避免在多个本地文件标签页中同时修改数据。
在页面顶部“演示说明与数据备份”中导出 JSON 备份；另一台电脑打开 HTML 后导入 JSON 即可迁移完整演示数据。
将 HTML 或 ZIP 复制给别人不会自动带走你后续的操作数据；需要另附 JSON 备份。
恢复初始数据前请先备份。Excel 导出用于台账查看，JSON 用于完整恢复。

静态版范围
包含员工/管理员界面、批量申领与审核、整单校验后统一扣库、批量入库、Excel 模板导入导出、物资库批量调整、库存预警、站内通知、追溯、月报及规则式自然语言指令。
所有代码、样式、图标、Excel 组件与初始数据内嵌在 index.html 中，无 CDN 或 API 请求。
不同电脑不共享数据；演示身份可切换，不提供真实身份认证或生产权限隔离。
不接入企业微信登录/消息推送，不接在线大模型。正式多人协同请使用原服务端版本。
页面打开时检查并补生成上月月报，页面保持打开时每分钟检查；关闭页面后无法运行计划任务。

数据来源：重构时现有 demo 的独立数据快照（172 种物资、17 条入库、1 条申领明细）。原 demo 数据不会被本静态版修改。
